# RAG over arXiv Papers

A Retrieval-Augmented Generation system that answers questions about arXiv research papers on Retrieval-Augmented Generation itself — built end to end with a local vector store, local embeddings, a local LLM (Ollama), re-ranking, and a real quantitative evaluation suite.

> 🚧 Work in progress. Full documentation and evaluation results coming as the project is built out.
